# ZenithHabit Pro • Daily Habit Tracker & Streak Management App

ZenithHabit Pro is a modern, native-style Mobile & Web Daily Habit Tracking application built with a focus on discipline, accountability, and streak preservation.

## ✨ Features

- **🎯 Focused Home View**: Displays only today's pending tasks for minimum friction and maximum daily focus.
- **📈 Top Round Progress Chart**: Instant visual circular progress ring placed right at the top for real-time completion feedback.
- **🔥 Dedicated Streak Counter**: High-visibility fixed badge with real-time day tracking and **1-Chance Streak Freeze Shield**.
- **❄️ 1-Chance Streak Freeze Rule**: Automatic 1-day grace period for missed days to prevent accidental streak loss before resetting to 0.
- **⚡ Collapsible Today's Tasks**: Minimize or expand the daily task list to keep the interface compact and organized.
- **✓ Direct Habit Checkboxes**: Fast one-tap ticking next to each habit in a clean list-view layout.
- **📅 Historical Marksheet**: 31-day historical tracking matrix organized across Weeks 1 to 5. **Read-Only by default** with an explicit "Unlock Edit Mode" confirmation to prevent cheating.
- **📊 Graphical Analytics**: Interactive Weekly Bar Chart, 31-day consistency trend curves, and Top 10 Habits Leaderboard.
- **👤 Profile & Appearance**: Dedicated profile modal with photo upload, DiceBear avatar randomization, and instant **Dark Mode / Light Mode** switching.
- **🔔 Daily Reminder Alerts**: Automated push notification banners, SMS & WhatsApp daily streak reminders.

## 🚀 Getting Started

No build tools or complex setup required. Simply run locally using any standard static file server:

### Prerequisites
- Node.js or Python 3

### Running Locally
```bash
# Using Python
python3 -m http.server 3000

# Or using Node.js
npx serve .
```

Open [http://localhost:3000](http://localhost:3000) in your web browser.
